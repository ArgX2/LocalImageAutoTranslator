# Local Image Auto Translator 🚀

구글 번역(Google Translate) 페이지의 내장 컨트롤러와 크롬 확장 프로그램 시스템을 결합하여, 로컬 폴더 내의 다수 이미지를 연속으로 일괄 번역하고 자동 저장해 주는 인프라스트럭처 프레임워크입니다. 별도의 백엔드 서버 없이 웹 브라우저 샌드박스 환경 내에서 모든 자동화 파이프라인이 완결되는 효율적인 구조를 가지고 있습니다.

※본 프로젝트는 바이브코딩을 통해 제작되었습니다.※

## 📌 시스템 아키텍처 (Architecture)

본 프로그램은 크롬 확장 프로그램(Chrome Extension Manifest V3) 아키텍처 규칙에 따라 역할이 명확히 분리된 **컴포넌트 기반 분산 구조**를 따릅니다.


```


   [ 사용자 (User Interface) ]
     /                    \
(팝업 클릭)            (웹페이지 인터랙션)
   v                        v


+--------------+        +--------------------------+
|   popup.js   |        |        content.js        |
|  (UI & Link) |        | (핵심 비즈니스 로직/DOM제어)|
+--------------+        +--------------------------+
|                             |
+-------> [ storage.local ] <-+ (설정 동기화)

```

### 1. 컴포넌트 레이어별 역할
* **설정 및 메타데이터 (`manifest.json`):** `https://translate.google.com/*` 도메인에 대한 호스트 권한을 제안하여 보안성 및 격리성을 유지하는 매니페스트 설계도입니다.
* **클라이언트 팝업 (`popup.html` / `popup.js`):** 구글 번역의 이미지 탭(`op=images`) 진입을 유도하는 트리거 UI이자, 초기에 시스템 다국어 설정을 파싱하는 프론트 레이어입니다.
* **컨텐츠 스크립트 (`content.js`):** 구글 번역 웹페이지 내부(DOM)에 주입되어 커스텀 조작 패널을 삽입하고, 비동기 파이프라인 루프를 돌며 웹 페이지 엘리먼트를 제어(Automation)하는 핵심 비즈니스 로직 레이어입니다.
* **데이터 공유 저장소 (`chrome.storage.local`):** 팝업과 컨텐츠 스크립트 간의 실행 컨텍스트 격리를 극복하고 UI 언어 설정 상태를 동기화하는 백플레인 인프라입니다.

### 2. 핵심 메커니즘 및 패턴
* **비동기 재귀 루프 파이프라인:** 단일 스레드 기반의 `processNextImage()` 파이프라인을 구축하여 `[이미지 업로드] ➡️ [Shadow DOM 내 번역 감지 리스너] ➡️ [Canvas 가공] ➡️ [로컬 비동기 I/O 저장]` 단계를 순차적으로 순회합니다.
* **샌드박스 로컬 I/O (File System Access API):** 브라우저 보안 제약을 극복하기 위해 `window.showDirectoryPicker()`를 활용, 사용자가 허가한 특정 로컬 디렉터리 내에 `Translated` 서브 폴더를 생성하고 물리 파일 스트림을 직접 기록합니다.
* **상태 기반 비동기 제어:** 인터페이스의 동적 제어를 위해 `isProcessing`, `forceStop` 등의 글로벌 상태 플래그를 두어 중지 및 재시도 이벤트를 안전하게 트래킹합니다.

## 🛠️ 설치 방법 (Installation)

1. 이 리포지토리를 clone 하거나 Zip 파일로 다운로드합니다.
2. 구글 크롬 브라우저를 열고 주소창에 `chrome://extensions/`를 입력하여 이동합니다.
3. 우측 상단의 **'개발자 모드(Developer mode)'** 토글을 켜서 활성화합니다.
4. 좌측 상단의 **'압축해제된 확장 프로그램을 로드(Load unpacked)'** 버튼을 클릭합니다.
5. 본 프로그램의 소스 코드가 포함된 폴더(`manifest.json`이 있는 폴더)를 선택하여 등록합니다.

## 📖 사용 방법 (How to Use)

### Step 1. 구글 이미지 번역 페이지 진입
* 브라우저 툴바에서 **Local Image Auto Translator** 아이콘을 클릭합니다.
* **구글 이미지 번역 열기** 버튼을 누르면 자동화 컨트롤러가 주입된 구글 번역 페이지가 새 탭으로 열립니다.

### Step 2. 언어 설정 및 폴더 선택
* 새로 열린 구글 번역 페이지 우측 하단에 생성된 **자동 번역 컨트롤러**를 확인합니다.
* 컨트롤러 내부의 셀렉트 박스에서 **원본 언어**와 **번역 언어**를 지정합니다. *(주의: 언어 변경 시 페이지가 자동으로 새로고침 됩니다)*
* **`1. 폴더 선택`** 버튼을 누르고 브라우저 파일 접근 권한 승인 후, 번역할 대상 이미지들이 모여 있는 로컬 폴더를 지정합니다. 

### Step 3. 번역 파이프라인 실행
* 폴더 내 이미지 파일들이 정상적으로 스캔되면 파일 개수가 UI에 표시됩니다.
* **`2. 번역 시작`** 버튼을 누르면 순차적으로 구글 번역 인프라에 이미지가 업로드되며 작업이 진행됩니다.
* 번역이 완료된 파일은 원본 폴더 내부에 자동으로 생성되는 `Translated` 폴더 안에 시스템 규칙에 맞춘 파일명(`[원본파일명]-translated-[언어코드].[확장자]`)으로 순차 저장됩니다.

### Step 4. 예외 처리 제어
* **강제 중지:** 작업 중 문제가 발생하거나 프로세스를 멈춰야 할 때 `강제 중지` 버튼을 눌러 파이프라인을 안전하게 탈출합니다.
* 이미지 다시 넣기 (Retry): 구글 서버 응답 지연 등으로 인해 이미지 로드가 지연될 경우, `이미지 다시 넣기` 버튼을 눌러 현재 인덱스의 작업을 즉시 리셋하고 재시도할 수 있습니다.

## ⚠️ 아키텍처적 한계 및 주의사항
* **타깃 DOM 의존성:** 본 프로그램의 셀렉터 패턴은 구글 번역 페이지의 특정 클래스명(`img.Jmlpdc`) 및 특정 SVG 패스 데이터(`M19 6.41L17.59 5`)에 강하게 결합(Tight Coupling)되어 있습니다. 따라서 구글의 웹 인터페이스 구조가 업데이트될 경우 셀렉터 레이어의 유지보수가 필요할 수 있습니다.
